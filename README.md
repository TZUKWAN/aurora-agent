# 🏆 Aurora Agent (极光赛事智能体)

![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)
![Playwright](https://img.shields.io/badge/Playwright-Enabled-green)
![Swarm](https://img.shields.io/badge/Multi--Agent-Swarm-orange)

Aurora Agent 是一个专为**大学生创新创业大赛（“互联网+”、“挑战杯”、“三创赛”等）**量身打造的国家级金奖级 AI 商业计划书与路演生成系统。

系统彻底摒弃了传统大模型“假大空”的生成弊病，内置 **7大金牌赛事导师智能体矩阵**、**独立财务核算沙盘**、**反幻觉联网RAG库** 以及 **独创的全域图文融合排版引擎**。仅需输入初步的创意，即可自动输出符合国赛标尺（30-30-20-20制）的高保真图文版 Word 商业计划书与路演 PPT。

## 🌟 核心杀手级特性

### 1. 👺 七子矩阵：魔鬼级国赛评审团
完全对标真实国家级赛事的严苛审查逻辑，构建了以总教头为核心的多智能体协同网络，杜绝客套话，实行“压力抗辩”：
- **💰 VC分析师**：死磕你的商业转化路径与融资造血能力。
- **🔬 技术评审教授**：无情剥开技术壁垒，打掉伪创新。
- **⚖️ 严苛判官**：专攻数据涉假，逼迫给出核心【量化指标】。
- **🎤 路演王牌教练**：通过分类题库，随机抽取高压问题进行模拟答辩演练。
- **✍️ BP金牌写手** / **📜 政策红头专家** / **👑 金奖总教头**。

### 2. 📊 Deterministic 财务推算沙盘 (Financial Sandbox)
大模型算账必然出错？在这个系统中绝对不会。
- **纯 Python 物理核算**：大模型仅负责提取“客单价”、“月复合增长率”、“固变成本”等常数，交由内置沙盘引擎进行严格的 3 年期循环计算。
- **零误差成表**：绝对严丝合缝的输出毛利率、净利率及盈亏平衡点（BEP月份），让你的财务报表再也挑不出数据冲突的致命伤。

### 3. 🌐 反幻觉联网检索 (Web Search RAG)
系统为导师强制装载了开源联网模块（基于 DuckDuckGo `ddgs`）。当触发到“市场规模(CAGR)”、“政策法规”、“竞品市场份额”等敏感数据时：
- AI 必须自主强制联网溯源，截取最新的真实研报摘要。
- 输出的数据必须带来源背书角标（例如：*数据来源：2024智研咨询*），彻底告别大语言模型满嘴跑火车。

### 4. 🎨 UI/图表自动图文大一统引擎 (Playwright Renderer)
让自动生成的商业计划书拥有惊艳的“视觉”。
- **反模板化动态代码生成**：我们内置了 `VisualDesigner` 前端设计智能体，它会针对不同的项目，纯手敲高B格的 HTML/CSS (附带ECharts)。
- **无损无头截屏**：后台 `Playwright` 毫秒级静默启动浏览器渲染动画，咔嚓截取高精度 PNG。
- **自适应自动排版**：图片将无缝、并居中地流转入生成的 Word大纲 和 演示 PPTX 中。别人用 AI 生成干巴汉字，你产出的是带深色驾驶舱UI面板或财务拆解柱状图的高清计划书。

### 5. 💾 SQLite 断点持久化记忆 (Session Memory)
轻量化的本地数据库架构守护你的生成进度：
每生成一个章节或一次讨论，进度状态都将通过 `session_db` 被落盘锁定。遇到断网宕机，或你需要指令 AI 单独重写“商业模式”这一章节时，系统秒级读取上下文热启动，再也无需从头氪金复写全篇。

## 🚀 快速开始

### 环境依赖
确保你使用的是 **Python 3.10+**。

```bash
# 1. 克隆代码仓库
git clone https://github.com/TZUKWAN/aurora-agent.git
cd aurora-agent

# 2. 安装所有依赖及可选增强包 (.env 中配置 API 等)
pip install -e .[all]

# 3. 安装无头浏览器内核（核心！用于视觉生成工具绘图库支持）
playwright install chromium
```

### 运行方式

项目包含全套的 CLI 和核心运行包，最基本的计划书编排只需调用命令行或是引入包体：

```bash
# 待添加：启动整个项目的交互式 CLI 指令
python -m aurora
```

*(系统将自动在根目录下创建缓存库 `.aurora_sessions.db` 并生成各类产出与数据)*

## 📂 项目模块解剖

```text
aurora/
 ├── agent.py               # Aurora 核心统筹控制与注册入口
 ├── business_plan/         # BP结构、Word 图文排版组装生成器 (generator.py)
 ├── competition/           # 大赛赛道知识图谱与打分阈值库 (30-30-20-20国标)
 ├── evaluation/            # 赛事评委打分、压力测试驱动引擎
 ├── financial/             # 【重磅】纯代码驱动的确定性三年财务沙盘引擎
 ├── memory/                # SQLite3 本地防灾防断点图持久化状态记忆
 ├── presentation/          # 带有图像挂载接口的路演 PPT 生成器
 ├── prompts/               # 存放超级严苛系统设定的国奖教头核心 prompt
 ├── swarm/                 # 7大金牌智能体的分布式推演架构
 ├── tools/                 # 各类硬核能力 (联网搜研报web_search、路演质询等等)
 └── visuals/               # 【重磅】AI动态手搓HTML前端+Playwright无头截图工厂

legacy_scripts/             # 存放旧版本脏乱差实验脚本的归档区
test_*.py                   # 模块断言防爆全量整合自动测试
```
